## 5. Target customers

### Primary ICP (2027)
**South Florida owner-operated firms with 10–100 employees** that already use several SaaS tools, carry sensitive data, and have an owner or operations manager who feels admin overload.

| Segment | Pains | Lead offers |
| --- | --- | --- |
| **Law firms** (PI, estate, real estate) | Intake, document drafting, privilege concerns | A, B (intake and drafting), C (private AI) |
| **Medical, dental and therapy practices** | Scheduling, prior auth, HIPAA | A, C, B (front-office agents, with a BAA-capable stack) |
| **CPA, bookkeeping and wealth firms** | Seasonal crunch, client document chase | B, C |
| **Property management and real estate** | Maintenance requests, tenant comms, reporting | B, D |
| **Field-service companies** (residential tree care, landscaping, HVAC, construction) | Dispatch, estimates, crew documentation, safety records | A, B, H. Erich screens every prospect here for the employer boundary: no vegetation-management or line-clearance contractors and no known FPL/NextEra vendors; decline when unsure |

### Secondary ICP
- **Small software and dev teams** (5–30 engineers) that want Kubernetes, GitOps, CI/CD and agent-assisted development workflows set up properly. Remote and national. Reach them through the KubeCraft and CNCF communities and GitHub (see [§8](09-marketing.md) for the full remote ICP and channel plan).

### Phase-2 ICP
- **Utility contractors, municipalities, electric co-ops, and UVM vendors** (Line E).

### 8.3 Remote ideal customer profiles

| Segment | Why they buy remotely | Where to find them |
| --- | --- | --- |
| **US SMBs (10–100 staff) in professional services**, nationwide | Same pains as the local ICP; comfortable with Zoom-based vendors since 2020 | LinkedIn, vertical associations and newsletters, partner referrals |
| **Startups and small SaaS / dev teams** (seed to Series A) | Need DevOps and agent infrastructure without a full-time platform hire | GitHub, Hacker News "Who wants to be hired / freelancer" threads, KubeCraft, CNCF Slack, Contra, Toptal (once eligible) |
| **Agencies and MSPs without AI depth** (white-label) | Want to resell agent and MCP services under their own brand | LinkedIn outreach, MSP communities and peer groups, channel partnerships |
| **AI tool vendors and open-source projects** | Need integration engineers, implementation partners and technical content | Their partner programs, Discords, GitHub issues |
| **Utility contractors and co-ops outside FPL territory** (phase 2, with employer clearance) | Domain expertise is scarce and portable | Industry events (e.g., UAA, TCIA, T&D World), LinkedIn |
